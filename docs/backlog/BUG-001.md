# BUG-001: Older expenses never show up when paging

**Reported by:** Linh (Finance)
**Severity:** High
**Environment:** Chrome 130, macOS 15, app at http://localhost:3000, seeded data

## Steps to reproduce

1. Open the app. The list shows 10 rows and the pager says "Page 1 of 2 (12 total)".
2. Click **Next**.

## Expected

Page 2 shows the remaining 2 expenses (the two oldest ones from January).

## Actual

Page 2 is completely empty. The pager still says "Page 2 of 2 (12 total)", but there are no rows.
Clicking **Prev** brings the first 10 back. I can never see expenses 11 and 12 in the UI.

## Notes

Same thing happens with the category filter on: filter "food" says 5 total, all on one page, fine.
Without the filter I lose the tail of the list. I also tried calling the API directly with
`?page=2&limit=10` and got `"items": []`, so it is not just the web page.
